把本地原生 FreeCAD 接入 4yi CAD 云端Connect your local FreeCAD to 4yi CAD Cloud

在你自己电脑的 FreeCAD 里安装 4yi Companion 插件,连上云端 AI 控制面——用一句话生成模型、自动回载到本地、把版本存回云端。全程约 5 分钟。 Install the 4yi Companion add-on in FreeCAD on your own machine and connect it to the cloud AI control plane — describe a part in one sentence, have it generated in the cloud, loaded back into your local FreeCAD, and pushed to the cloud as a version. About 5 minutes end to end.

i 为什么要 Token?云端 API 平时用网页 SSO 登录保护,而桌面插件走不了浏览器登录流程——所以改用一枚专属 API Token 作为凭证。Token 只能由已登录的你在网页上签发,插件带着它连入。 Why a token? The cloud API is normally protected by web SSO login, but a desktop add-on can't run a browser login flow — so it uses a dedicated API token as its credential instead. The token can only be issued by you, signed in, on the web page; the add-on connects with it.

  2. 2

    通过 Addon Manager 安装Install with Addon Manager

    打开 FreeCAD 首选项 → Addon Manager,在 Custom repositories 区域点击 +。Repository URL 填入下面的分发仓,Branch 填 main。该分发仓会从 4yi CAD 主仓自动同步。 Open FreeCAD Preferences → Addon Manager. Under Custom repositories, click +. Use the distribution repository below and set Branch to main. This repository is automatically synchronized from the 4yi CAD source repository.

    分发仓Distribution repository https://github.com/4yi-ai/cad-addon

    保存首选项后打开 工具 → Addon Manager,搜索仓库名 cad-addon 并安装。FreeCAD 1.1 的自定义仓库搜索暂时不匹配显示名 4yi CAD Companion。以后版本更新也通过 Addon Manager 完成。 After saving Preferences, open Tools → Addon Manager, search for the repository name cad-addon, and install it. FreeCAD 1.1 custom-repository search does not initially match the display name 4yi CAD Companion. Future updates are also handled by Addon Manager.

    ! 当前要求插件版本 0.5.2。如果 Addon Manager 无法使用,再采用源码 ZIP 兜底:运行 print(App.getUserAppDataDir() + "Mod") 确认目录,下载 https://github.com/4yi-ai/4yi-cad/archive/refs/heads/main.zip,完全退出 FreeCAD 后复制 4yi-cad-main/freecad-addon/fouryi_cad_companion。 The required add-on version is 0.5.2. If Addon Manager is unavailable, use the source ZIP fallback: run print(App.getUserAppDataDir() + "Mod") to identify the directory, download https://github.com/4yi-ai/4yi-cad/archive/refs/heads/main.zip, completely quit FreeCAD, then copy 4yi-cad-main/freecad-addon/fouryi_cad_companion.
  3. 3

    重启,切换到 4yi 工作台Restart, switch to the 4yi workbench

    重启后,点左上角的 工作台(Workbench)下拉框,选择 4yi CAD。连接设置和 AI 面板都在这个工作台里——不在 Tools 菜单。打开「4yi 支持包」并确认 addon_version 为 0.5.2。 After restarting, click the Workbench dropdown at the top-left and pick 4yi CAD. The connection settings and AI panel live in this workbench — not in the Tools menu. Open "4yi Support Bundle" and confirm that addon_version is 0.5.2.

  5. 5

    开始用:生成 → 回载 → 存回云端Use it: generate → load back → push a version

    在 4yi 面板输入一句 prompt(例如「一个 20mm 立方体,中心开 6mm 通孔」),云端 AI 生成后,模型作为 FCStd 自动回载进你本地的 FreeCAD;满意就「保存到云端」存成一个新版本。 Type a prompt in the 4yi panel (e.g. "a 20 mm cube with a 6 mm through-hole in the center"). The cloud AI generates it and the model is loaded back into your local FreeCAD as an FCStd; when you're happy, "Save to cloud" stores it as a new version.
